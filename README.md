# Calculadora EBAC

## Sobre o projeto

Este projeto foi desenvolvido como atividade do curso de Analista de Dados da EBAC.

O objetivo é criar uma calculadora com operações matemáticas básicas, utilizando Bash e Python.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Verificação de divisão por zero
- Aviso para opções inválidas
- Suporte a números decimais na versão Python

## Tecnologias utilizadas

- Ubuntu Linux
- Bash
- Python
- Git e GitHub

## Arquivos

- `calculadora.sh`: calculadora desenvolvida em Bash.
- `calculadora.py`: versão aprimorada da calculadora em Python.

## Como executar

**Bash:**

```bash
chmod +x calculadora.sh
./calculadora.sh
```

**Python:**

```bash
python3 calculadora.py
```
